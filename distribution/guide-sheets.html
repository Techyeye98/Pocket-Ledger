Settings → Sync & Sheets

Connect your own Sheet.

Optional: the phone remains your primary ledger. Use the Android template and Android script together.

  1. Copy the Android template

    Open the Android Sheet template from Download. In the copy, use Extensions → Apps Script. Replace the code with the current Android script and save.

  2. Prepare its reports

    Run setupPocketLedger once and authorize. Run setupCleanTransactions for the readable Transactions report and hidden Sync Support storage.

  3. Deploy a Web app

    Deploy → New deployment → Web app. Execute as Me; choose Anyone for app access. Keep the resulting /exec URL private. For an existing deployment, edit it to a New version and keep its URL.

  4. Connect from the app

    Set Web App URL. Use Test Connection, then Sync Now. Refresh Sheet dashboard rebuilds the report from synced data; it does not upload the phone’s ledger.

What is stored where?

Transactions is the clean report. Dashboard shows balances and people dues. Sync Support holds technical records. Edit in the app or Dashboard; keep support storage intact.

Connected saves can attempt sync automatically; there is no scheduled background sync. Sync Now merges the full financial ledger by stable IDs. Split bills stay on the phone.

Questions you might have.

Why did cleared report rows come back?

Transactions is rebuilt from stored sync data. Clearing report cells does not clear the financial ledger. Use the app’s deliberate history action for a fresh start; keep hidden Sync Support intact.

My new entries are not in the Sheet. What next?

Check the Web App URL ends in /exec and the current script is deployed as a new version. Test Connection, then Sync Now. A dashboard refresh alone does not send local entries.

Should iOS use this Android script?

No. The iOS Shortcut is a separate expense-to-Sheet workflow with its own template and script. Android accounts, the financial ledger and standalone splitter are not features of that Shortcut.
